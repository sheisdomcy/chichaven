# Chichaven - Clothing Website

Chichaven is a responsive fashion and clothing business website for a clothing brand in Enugu, Nigeria. It was built as a New Horizon Web Development project using HTML, CSS and JavaScript.

## About the Project
Chichaven introduces the brand, showcases its clothing products and services, and allows visitors to contact the business. The website is fully responsive and works on mobile phones, tablets and desktop computers.

## Pages
- **Home (index.html)** - Welcome message, introduction and navigation
- **About (about.html)** - Background, mission and vision of Chichaven
- **Services (services.html)** - At least 3 products/services with descriptions and images
- **Contact (contact.html)** - Contact information and contact form

## Technologies Used
- **HTML:** Semantic structure, headings, links, images, lists and forms
- **CSS:** External stylesheet (style.css), Flexbox, Grid, media queries, box model, positioning
- **JavaScript:** External file (script.js), variables, functions, event handling, form validation and interactive feedback

## Features
- Responsive design with CSS media queries
- Flexbox layout in navigation and service sections
- CSS Grid layout for products/services
- JavaScript validation for the contact form (Full name, Email, Subject, Message)
- Interactive feedback when users interact with the website
